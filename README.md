# Cresencio's FreeStorage - Disk Cleanup Application

This is a Python based application designed to help user's **analyze and clean temporary files, caches, and other unnecessary data** to safely free up disk space. 
**ONLY WORKS ON Windows** 
Currently working on a simple GUI that will be pushed as soon as it is done.

---

## Features
- Scan and display storage usage across drives or directories
- Delete temporary or unnecessary files to reclaim space

## Requirements
- **Python 3.8+**

---
## Instructions
- Ensure Python is installed
- If not go to python.org/downloads/ and download the latest version
- During install ensure to check **"Add Python to PATH"**
- Ensure customtkinter is installed
- If not type pip install customtkinter in commandline.
- Once installed, open up a commandline
- Use 'cd' to get to folder where freeStorage.py is
- Type 'python freeStorage.py'

---
## Notes
- This tool does **not** remove system-critical files
